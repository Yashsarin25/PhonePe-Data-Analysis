# PhonePe Data Analysis Using Python

## Project Overview
This project explores PhonePe transaction data using Python to identify patterns, trends, and insights through data analysis and visualization.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Explore and understand the PhonePe dataset.
- Perform data analysis using Pandas and NumPy.
- Identify patterns and trends in the available transaction data.
- Create visualizations to communicate analytical findings.
- Derive insights from the dataset to support data-driven understanding.

## Project Files
- `Project1_PhonePay.ipynb` — Jupyter Notebook containing the Python code, analysis, and visualizations.
